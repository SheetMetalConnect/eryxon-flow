A tester asked whether the operation sequence is a real dependency or just
information. It was information, and the terminal's buffer did not even look at it.
That question turned into the release: the buffer follows the routing, one switch
enforces the sequence, and every rule now lives in the database where the terminal,
the REST API, webhooks and the MCP server all go through it.

There is no compatibility layer. Webhook consumers move to the new payload and
signature, MCP clients speak protocol 2026-07-28, API clients handle `409` for rule
violations. The changelog lists the migrations to apply in order.
