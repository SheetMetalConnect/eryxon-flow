This release concentrates on reliability and maintenance. Duplicate mobile pages,
unused widgets, and divergent database types have been removed. The application
uses the same responsive interface across device sizes; PWA installation is an
optional build setting.

Self-hosters must apply the included database migrations before deploying the
matching frontend and Edge Functions. Back up the target and check existing tenant
references first. Terminal users must verify their PIN again after upgrading.

Community retains its existing Business Source License 1.1. Premium capabilities
remain separate. See the repository changelog and release runbook for detailed
validation and deployment requirements.
