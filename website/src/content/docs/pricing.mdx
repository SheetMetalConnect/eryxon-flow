Eryxon Flow comes in two editions. Start with the hosted trial to validate fit, then run the Community edition yourself or talk to us about Premium.

## Try it first

Start with the hosted version to validate workflow fit before you deploy anything:

- [Open the hosted version](https://app.eryxon.eu) — best for initial operator and supervisor walkthroughs

## Community

Free, self-hosted, and source-available under the Business Source License 1.1. The source is on GitHub — read it, modify it, self-host it. Free production use is granted for a **single production site** (one facility or workshop) for your own internal operations.

- Full shop-floor MES core: job/part tracking, cell tablets and work queues, browser-based 3D part viewer, REST API + webhooks
- Interface in English, Dutch, and German
- Provided **AS IS**, with minor fixes only
- Support via the community and GitHub issues (no SLA)
- [Self-Hosting Guide](/guides/self-hosting/) · [Deployment Guide](/guides/deployment/)

> Each released version automatically converts to its Change License, GNU GPL v2.0 or later, four years after that version's release.

## Premium

Commercial edition sold direct by Sheet Metal Connect e.U., with an **SLA included**. Required for multi-site use or for offering the app as a service. Delivered hosted (Cloud) or on-premise.

Premium adds:

- All ERP connectors and add-ons
- Monitoring
- Multi-site management with a central hub dashboard
- Advanced workflows
- Whitelabeling
- Advanced 3D: nesting, unfold, and annotations

Pricing is on request. [Contact sales](https://vanenkhuizen.com) to discuss your requirements.
